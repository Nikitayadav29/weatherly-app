# Weatherly 🌦️

A responsive weather forecasting web app that shows real-time weather data with a clean, simple UI.

## Features
- Search weather by city name
- Displays temperature, humidity, wind speed
- Weather icons based on conditions (sunny, rain, snow, clouds, thunder)

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Clone this repo
2. Open `index.html` in your browser
